Conexión con Supabase (Nube Gratuita)

Permite sincronizar los datos en tiempo real entre múltiples dispositivos

¿Cómo obtener estos datos en Supabase?

1. Entra en supabase.com con tucumanbbcuotas@gmail.com.

2. Abre tu proyecto ➔ Project Settings ➔ API.

3. Copia la Project URL y la clave anon public.

🛠️ Script para crear las tablas en Supabase

Si es la primera vez que usas este proyecto en Supabase, debes crear las tablas (socios, cuotas y pagos). Solo pulsa "Copiar Script SQL", entra en SQL Editor de tu proyecto en Supabase, pega el texto y haz clic en RUN.

Usuarios y Roles del Sistema

Permisos diferenciados para Administradores, Secretarios y Entrenadores

👑 Administrador Acceso Total

Acceso a cobranzas, reportes, eliminar registros, configuración del club y gestión de usuarios.

📑 Secretario Operativo

Puede cobrar cuotas, emitir recibos y gestionar socios. Sin permiso para dar de alta actividades, modificar precios de cuotas, eliminar ni alterar configuración.

🏀 Entrenador Deportivo

Visualiza la nómina de socios para comprobar cuotas al día o deuda y avisar por WhatsApp. Sin acceso a caja.
